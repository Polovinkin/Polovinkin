## Hi, I'm Dmitrii Polovinkin

I'm a traveler and data engineer, if we look at the main activities I do. Currently work as Senior Data Engineer in Leroy Merlin Russia (now called Lemana Pro). Have been to 80 countries and 180+ regions of those countries in total.

My current pet/side projects are:
- [Vagabondity Walks](http://www.youtube.com/@vagabondity) YouTube channel. I create city walks in basically all cities I visit in my active travels around the world. There are more than 200+ city walks and 1k+ subscribers.
- [TravelPinHunt.com](https://travelpinhunt.com) - crowd-sourced collectors guide to buying travel pins worldwide. Built this website as a thing I wanted to exist to help me in my pin-collecting hobby. Almost half of all the locations on the website are already added by other contributors.
- [YouTube Localizer by Vagabondity](https://github.com/Polovinkin/YouTube-Localizer) - a local-run app with an easy setup which allows YouTube creators to localize their videos metadata in bulk and for free using understandable UI. Built it for my YouTube channel originally, and decided to share it so other can use it too. My goal is to make it the best tool available for YT metadata translations.

I'm also an experienced OpenStreetMap contributor, my profile there is [dpolovinkin](https://www.openstreetmap.org/user/dpolovinkin).
